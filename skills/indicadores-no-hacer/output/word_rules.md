# Reglas de salida Word

Uno de los tres formatos posibles. La elección del formato y las reglas comunes están en `output/formats.md`.

## Principios generales
- Generar `.docx` solo cuando el módulo o el usuario lo solicite.
- Usar tamaño A4 salvo que el contenido exija otra configuración.
- Márgenes adecuados para impresión y legibilidad.
- Tipografía legible, jerarquía clara, bordes discretos y uniformes.
- Evitar tablas que sobrepasen el área útil de página.
- Usar orientación horizontal cuando sea necesaria para mantener legibles las columnas.

## Tabla de indicadores (construcción de indicadores)
Columnas exactas:
`Recomendación | Tipo | Numerador | Denominador | Aclaraciones | Excepciones`

- Una recomendación = un bloque visual.
- Si genera varios indicadores, fusionar verticalmente de forma real Recomendación, Aclaraciones y Excepciones.
- Tipo, Numerador y Denominador: una fila por indicador.
- La línea divisoria interna entre indicadores solo atraviesa Tipo, Numerador y Denominador.
- Entre recomendaciones, línea horizontal completa en las seis columnas.
- No repetir contenido en celdas fusionadas.
- Un único indicador = una sola fila.
- Varias recomendaciones = una única tabla.

## Colores de la revisión bibliográfica
- Texto original: negro.
- `[Añadido]` + texto añadido + sus referencias: azul.
- `[Revisar]` + explicación + sus referencias: rojo.
- En celdas mixtas, colorear solo el fragmento nuevo.
- Bibliografía final: negro.

## Ficha del panel de expertos
- A4, lista para imprimir.
- Encabezado con nombre, enfoque y escala 1–9.
- Para cada dimensión: pregunta, `Puntuación: ___/9`, espacio suficiente para observaciones.
- Cierre con pregunta abierta sobre modificaciones y espacio de respuesta.
- Diseño compacto, profesional y sin contenido adicional.
